# ДАЛЬТУР — прототипы сайтов

Два разных проекта в одном репозитории.

## 1. `hunchun/` — рабочий каркас, то что заказано

Лендинг «Туры в Хуньчунь» по брифу от 25.09.2026. Главная-каталог и девять
страниц туров (от 2 дней / 1 ночи до 10 дней / 9 ночей), сквозная
перелинковка, места под видео Яндекс.Видео.

Без цен, без форм — только звонок и мессенджеры, как просил заказчик.
Программы туров — рыба, тексты присылает заказчик.

Страницы генерируются: `python3 hunchun/build.py`. Под Яньцзи меняется
только блок `CITY` в начале скрипта.

Требования и очерёдность — в [TZ.md](TZ.md).

## 2. Корень — прототип редизайна dal-tour.ru

Свёрстан по макету Cloud Decision до того, как разобрали бриф. Заказчику
формат подошёл, но нужен другой город, поэтому лежит здесь как образец
дизайн-системы.

| Файл | Что это |
|---|---|
| `index.html` | Главная |
| `harbin.html` | Направление «Харбин» — 14 туров, фильтры, сортировка |
| `tur-harbin-5.html` | Карточка тура |
| `style.html` | Гайд стиля: палитра, типографика, компоненты |

## Технологии

Чистые HTML + CSS + vanilla JS. Сборки и зависимостей нет.

Локально:

```bash
python3 -m http.server 4173
```

Адаптив mobile-first, брейкпоинты 768 и 1100 px. Дизайн-токены — в
`assets/css/main.css`, блок `:root`.
