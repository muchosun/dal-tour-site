# ДАЛЬТУР — прототип редизайна

Статический прототип редизайна сайта туроператора «ДАЛЬТУР» (Владивосток).
Свёрстан по макету из Cloud Decision, содержание сверено с текущим сайтом
dal-tour.ru (74 тура, 10 направлений).

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная |
| `harbin.html` | Направление «Харбин» — 14 туров, фильтры по транспорту и длительности, сортировка |
| `tur-harbin-5.html` | Карточка тура «Харбин 5 дней / 4 ночи» |
| `style.html` | Гайд стиля: палитра, типографика, компоненты, правила |
| `TZ.md` | Техническое задание и очерёдность работ |

## Технологии

Чистые HTML + CSS + vanilla JS. Сборки нет, зависимостей нет — можно открыть
`index.html` напрямую или отдать любым статическим сервером.

Локально:

```bash
python3 -m http.server 4173
```

## Адаптив

Mobile-first. Брейкпоинты: 768 px (планшет) и 1100 px (десктоп).
Дизайн-токены — в `assets/css/main.css`, блок `:root`.

## Ограничения прототипа

- Бэкенда нет: формы собирают данные и открывают WhatsApp с готовым текстом.
- `[ЦЕНА]` и подобные плейсхолдеры — данных нет и в текущей базе сайта.
- Иллюстрация первого экрана — заглушка под существующий фирменный баннер.
